# prototype — النموذج الأولي للعرض والتجربة

مجلد مستقل تماماً عن كود التطبيق، مخصص لعرض «جرعة» على المستثمرين والمستخدمين التجريبيين
من دون تثبيت Xcode أو Expo أو ربط Firebase. يعمل بفتح ملف HTML في أي متصفح، على الحاسوب أو الجوال.

## المحتويات

| المسار | الغرض |
|---|---|
| `index.html` | صفحة العرض للمستثمرين: المشكلة، الحل، المزايا، نموذج العمل، وزر يفتح النموذج التفاعلي |
| `demo/index.html` | النموذج التفاعلي داخل إطار هاتف: الترحيب، الدخول، الرئيسية، الأدوية، التقويم، شركاء الرعاية، الذكاء، الصحة، وضع الزهايمر |
| `demo/data.js` | البيانات التجريبية (مريضة وهمية «أم خالد» بخمسة أدوية وموعدين وشريكَي رعاية) |
| `DEMO_SCRIPT.md` | سيناريو عرض مدته 5 دقائق مع نقاط الحديث لكل شاشة |
| `assets/` | أيقونة التطبيق |

## التشغيل

الطريقة الأسهل: افتح `prototype/index.html` مباشرة بالنقر المزدوج.

لعرضه على جوال في الشبكة نفسها أو لمشاركة رابط مؤقت:

```bash
cd prototype && python3 -m http.server 8080
```

ثم افتح `http://<عنوان-جهازك>:8080` من الجوال. النموذج متجاوب: على شاشة الجوال يملأ الشاشة كاملة بلا إطار هاتف.

## ما الذي يفعله النموذج وما لا يفعله

- **يفعل:** يحاكي التدفقات الأساسية بنفس الألوان والخط (Cairo) والقياسات الموصوفة في `DESIGN.md`. تأكيد الجرعة وتأجيلها يحدّثان حلقة التقدم والسجل فوراً. التبديل بين الوضع الداكن والفاتح، وتفعيل «وضع الزهايمر» يكبّر العناصر ويبسّط الشاشة الرئيسية.
- **لا يفعل:** لا يتصل بـ Firebase ولا يحفظ شيئاً. تحديث الصفحة يعيد البيانات الأصلية. كل الأسماء والأرقام وهمية.

## التحديث

النموذج لا يُبنى من كود التطبيق تلقائياً. عند تغيير تصميم شاشة في التطبيق الحقيقي، عدّل الشاشة المقابلة في `demo/index.html`
وحدّث `demo/data.js` إن لزم. الألوان في أعلى ملف الـ CSS مطابقة لـ `mobile/src/theme.ts` و`JorahTheme.swift`.
