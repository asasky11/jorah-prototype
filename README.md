# jorah-prototype — صفحة التعريف والنموذج التفاعلي

**الرابط العام:** https://asasky11.github.io/jorah-prototype/ — يُنشر تلقائياً من فرع `main` عبر GitHub Pages عند كل `git push`.
النموذج التفاعلي وحده: https://asasky11.github.io/jorah-prototype/demo/

مجلد مستقل تماماً عن مستودع التطبيق (`jor'ah App`). كل تطويرات العرض والنموذج التفاعلي تُضاف هنا، لا في مجلد التطبيق.
يعمل بفتح ملف HTML في أي متصفح دون تثبيت أو خادم.

## المحتويات

| المسار | الغرض |
|---|---|
| `index.html` | صفحة الهبوط (عربية RTL): الفكرة، الرسالة والرؤية والقيم، الخدمات الخمس، كيف يعمل، الأثر على المستفيد، المنصات، وزر يفتح النموذج. تعرض النموذج حياً في إطار هاتف داخل البطل. |
| `demo/index.html` | النموذج التفاعلي داخل إطار هاتف: الرئيسية، الأدوية (+ استيراد وصفة)، التقويم الشهري، ملفي وشاشاته الفرعية (شركاء الرعاية، موقعي، ملفي الطبي، بطاقة التعريف الطبية، تقرير الطبيب، صحتي وApple Watch، التقييمات، مساعد الرعاية الذكي، الإعدادات)، تفاصيل الموعد، التنبيهات، نافذة (+)، مسار جدولة الدواء من 5 خطوات، إضافة موعد. |
| `demo/data.js` | البيانات التجريبية (مريض وهمي «محمد عبدالله السالم، 67 سنة» بخمسة أدوية وموعدين وشريكَي رعاية). |
| `DEMO_SCRIPT.md` | سيناريو عرض مدته 5 دقائق مع نقاط الحديث لكل شاشة. |
| `assets/` | أيقونة التطبيق. |

## التشغيل

افتح `index.html` مباشرة بالنقر المزدوج. لعرضه على جوال في الشبكة نفسها:

```bash
cd /Users/abdullah/Desktop/devloper/jorah-prototype && python3 -m http.server 8080
```

ثم افتح `http://<عنوان-جهازك>:8080` من الجوال. على شاشة الجوال يملأ النموذج الشاشة كاملة بلا إطار هاتف.

روابط مباشرة إلى شاشة بعينها: `demo/#meds`، `demo/#calendar`، `demo/#profile`، `demo/#appt:a1`، `demo/#caregivers`، `demo/#insights`، `demo/#report`.

## ما الذي يفعله النموذج وما لا يفعله

- **يفعل:** يحاكي الشاشات بنفس الهوية (خط Cairo، الألوان `#0E3A5A` / `#2D8A6B` / `#D9534F` / `#D99B26`، خلفية `#F7F9FA`، بطاقات زجاجية بزوايا 20، أزرار كبسولية، أيقونات خطّية وظيفية). «تم التناول» و«تأجيل 15 دقيقة» يحدّثان حلقة التقدم والجدول فوراً. زر (+) يفتح نافذة مركزية ومنها مسار الجدولة من 5 خطوات (هوية الدواء ← الشكل الصيدلاني ← عدد المرات ← أول جرعة ← الجدول والتقييم) ويضيف الدواء فعلياً إلى القائمة. الوضع المبسّط لكبار السن والوضع الداكن من اللوحة الجانبية أو من الإعدادات.
- **لا يفعل:** لا يتصل بـ Firebase ولا يحفظ شيئاً. تحديث الصفحة يعيد البيانات الأصلية. كل الأسماء والأرقام وهمية.

## التحديث

النموذج لا يُبنى من كود التطبيق تلقائياً. عند تغيير تصميم شاشة في التطبيق الحقيقي، عدّل الدالة المقابلة في كائن `S` داخل `demo/index.html` وحدّث `demo/data.js` إن لزم. المرجع البصري: `docs/screens/*.png` و`DESIGN.md` في مستودع التطبيق.
